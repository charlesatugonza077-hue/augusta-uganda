# Augusta design workspace

Keep the visual system and experience decisions here as Augusta grows.

Suggested contents:
- `design-system.md` for colours, typography, spacing and components
- `user-flows.md` for enquiries, discovery calls and client follow-up
- `assets/` for approved images, icons and logo source files
- `wireframes/` for page layouts and feature sketches

Only use imagery and content that Augusta has permission to publish.
